# Gun Holsters 1.1.0 (Forge 1.20.1)
Requiere: Forge 47.x, Curios API 5.x, Vic's Point Blank (+ Civilian Gun Pack opcional).
- Funda de cintura (pistolas/revolveres) en la cadera y funda de espalda (rifles, escopetas, ametralladoras) en diagonal.
- Teclas (Controles > Gun Holsters): G = cintura, H = espalda. Cambio instantaneo, sin animacion.
- Config: gunholsters-common.toml (palabras extra para clasificar) y gunholsters-client.toml (posicion/rotacion).
Compilar: gradle build (JDK 17) o con la GitHub Action incluida.
